# 0006 — 履歴の最初の機構は「順応」(刺激の指数移動平均で実効的な反応の強さを下げる)

**読者:** 実装者(本人とコーディングエージェント)。
**日付:** 2026-09-24
**状態:** 採用(Phase 3)

## 問い

ロードマップの Phase 3 は「刺激の移動平均など、時定数の長い内部状態を 1 つ追加」。それを何にし、どこに作用させるか。

## 決定

- **遅い状態変数はスカラー m(t)。** 刺激振幅 s(t) の指数移動平均 `m += α (s − m)`、`α = 1 − exp(−1/τ)`、τ はステップ数(CLI では秒で指定し、steps/s を掛けて換算)。
- **作用先は実効的な反応の強さ(コードでは `stim_gain`)。** `g_eff = g / (1 + k·m)`。k = 0 で無効、そのとき Phase 2 の演算にバイト単位で触れない(テストで保証)。
- **m は更新の前に読む。** その step の応答は、過去の刺激だけで決まる。
- **m はモデルの状態の一部**としてチェックポイントに保存し、`metrics.csv` と `summary.txt` に記録する。
- **空間的な m(セルごと)は入れない。** まずスカラーで「履歴で応答が変わるか」を確かめる。
- **向きは履歴の指標に使わない**(Phase 2 で中立安定と分かったため)。応答は探針パルス中の総量増で測る。

## 理由

- Phase 2 で、一様な刺激への応答は総量の増加として即時に現れ、停止後に戻ることが分かった。その「応答の大きさ」を履歴で変えるのが、最も素直な履歴の定義。
- 順応は生物の感覚系にある一般的な性質で、「同じ音でも慣れる」は作品の意図(履歴が残る)と直結する。
- 実曲では RMS の正規化のせいで応答が小さいという Phase 2 の問題にも、長期平均で割る形は同じ機構で答えになる(ただし本決定は「割る」ではなく「反応の強さを下げる」形。正規化の置き換えは別途判断)。
- mu の変調に履歴を入れる案は、mu の許容幅が狭く(0.01 で可、0.02 で消滅)、履歴で mu が動くと消滅の危険が高い。

## 見送った案

- mu を m でずらす: 上記のとおり消滅しやすい。Phase 4 の可塑性で「感受性」を扱うときに再検討。
- 空間的な m: 音が当たった側だけ慣れる表現ができるが、Phase 3 の問い(履歴で差が出るか)にはスカラーで十分。
- 正規化を移動平均に置き換える(自動的な反応の強さの調整): 入力側の処理であり、モデルの内部状態ではない。Phase 3 の定義(内部状態を 1 つ追加)に合わせて、モデル側に置いた。

## 再検討する条件

- スカラーの m で履歴の差が出なければ、時定数と k の範囲を広げてから空間的な m を検討する。
- 実曲で応答が小さすぎる問題が残るなら、入力側の自動的な反応の強さの調整(直近数秒の RMS で正規化)を別の決定として追加する。
