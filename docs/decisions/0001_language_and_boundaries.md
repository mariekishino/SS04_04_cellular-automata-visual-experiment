# 0001 — 言語と責務の境界

**読者:** 実装者(本人とコーディングエージェント)。
**日付:** 2026-09-24
**状態:** 採用(実装時に環境を確認する)

## 問い

学習目的で C++ を使いながら、段階的な観察と、将来の別アプリへの接続可能性をどう保つか。

## 決定

- シミュレーションの中核は C++17。CMake でビルドする。
- 描画と音声の具体的な入出力から、中核を分離する。最初の描画候補は SDL3。
- このリポジトリは DJ Node Tool から独立させる。接続の方式は今は決めない。
- 42 の課題の C++98 要件を、この独立プロジェクトに持ち込まない。

## 理由

Game of Life で学んだ配列・近傍・盤面交換から、C++ の所有権、連続値の更新、数値安定性へ進むため。UI ライブラリを替えたり、将来ブラウザに載せたりする可能性があっても、モデルの振る舞いを保てるようにする。

## 見送った案

- C++98 で続ける: 42 の課題とは目的が違うので、制約を引き継ぐ理由がない。
- DJ Node Tool と同じリポジトリに置く: DJ 側も開発途中で、接続方式が未定のまま結合すると両方が縛られる。
