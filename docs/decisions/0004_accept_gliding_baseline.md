# 0004 — 刺激なしの基準動作として Orbium の直進を受け入れる

**読者:** 実装者(本人とコーディングエージェント)。
**日付:** 2026-09-24
**状態:** 採用(本人の判断)

## 問い

Phase 1 で本人が Mac の実機で観察した Orbium は、一定の速さで斜めに直進し、周期境界を通って流れ続ける。本人の当初のイメージは「個体が画面の中央に留まり、刺激がないときは小さく震えている」だった。このずれをどう扱うか。

## 決定

- 直進する動きを「刺激なしの基準線」として受け入れる。
- カメラ追従(重心が中央に来るように表示をずらす)は入れない。
- 別の生物(回転種・振動種)への切り替えも、いまは行わない。

## 理由

- 表示の細工やモデルの差し替えを足すほど、Phase 2 以降で「音の刺激による変化」を純粋に比較しにくくなる。基準が単調なほど、刺激による差は見えやすい。
- Orbium は総量や尾の切れ繋がりが絶えず揺れており、「震え」の要素はすでにある。満たしていないのは位置だけ。
- 周期境界の角で最大 4 分割に見えるのは表示上の見え方であり、個体は 1 つ。

## 見送った案

- カメラ追従(表示だけの変更、1〜2 時間): 最短で本人のイメージに近づくが、検証の純度を下げるという本人の判断で見送り。
- 別の生物を選ぶ: Phase 0 の探索に一部戻ることになる。

## 再検討する条件

Phase 2 で音の刺激を与えても、進む向きや速さ、形に変化が観察できない場合。または作品としての見せ方を決める段階(Phase 5 以降)で、位置の固定が必要になった場合。そのときはカメラ追従を最初の候補にする。
