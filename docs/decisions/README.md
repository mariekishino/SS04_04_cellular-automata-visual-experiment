# 設計上の決定

**読者:** 実装者(本人とコーディングエージェント)。
**役割:** 後から変える際に理由が必要な決定を残す。

## 書き方

各ファイルに次を書く。

- 日付
- 問い
- 決定
- 理由
- 見送った案
- 再検討する条件

ファイル名は `NNNN_短い名前.md`。番号は追加順。

## 注意

モデルの選択は Phase 0 の観察後に記録する。会話中に出た候補を、実験したことにして決定ログに入れない。
