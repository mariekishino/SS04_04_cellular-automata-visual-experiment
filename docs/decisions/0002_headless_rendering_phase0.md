# 0002 — Phase 0 の表示は PNG フレーム + 動画(headless)

**読者:** 実装者(本人とコーディングエージェント)。
**日付:** 2026-09-24
**状態:** 採用(Phase 0 のみ。Phase 1 で再検討)

## 問い

決定 0001 は描画候補を SDL3 としたが、Phase 0 を実装する VM に SDL3 が用意できない。どう表示するか。

## 決定

- Phase 0 では、各スナップショットを PNG に書き出し、`scripts/make_media.sh` で mp4 動画とラベル付きシート画像を作る。
- 停止・再開・リセットは headless 版として次のように対応付ける。停止 = `--steps` 到達で `state.bin` を書く。再開 = `--resume` で続きから。リセット = 同じ seed で最初から実行(決定的なので同じ結果になる)。
- PNG 書き出しは依存ライブラリなし(zlib の stored ブロック)。
- `Renderer` の境界は保つ。描画はモデルの `Grid` を読んで RGB を作るだけで、モデルは描画を知らない。

## 理由

- 実装環境(Ubuntu 24.04、exe.dev VM)の apt に `libsdl3-dev` がなく、X11 ヘッダも表示先(DISPLAY)もない。
- 本人は VS Code のリモート接続で作業するため、VM 上に窓が開いても見えない。PNG と mp4 なら VS Code でそのまま開ける。
- Phase 0 の目的は「2 モデルの動きを目と数値で比較する」ことで、対話的な UI は要件ではない([phases/00](../phases/00_model_exploration.md))。

## 見送った案

- SDL3 をソースからビルドする: X11/Wayland のヘッダが要り、ビルドに時間がかかる上に、窓が開いても見えない。
- SDL2 を apt で入れる: 0001 で SDL3 を候補にしており、Phase 0 のためだけに別版を入れる理由が弱い。

## 再検討する条件

Phase 1 で「長く観察する単体アプリ」を作る段階になったら、本人の手元の環境(Mac 等)で SDL3 が使えるかを確認し、窓表示の `Renderer` を追加する。そのとき PNG 出力は記録用として残す。
