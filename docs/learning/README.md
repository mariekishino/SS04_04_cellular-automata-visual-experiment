# 学習メモ

**読者:** 本人(制作者)。
**役割:** フェーズの実装中に生じた疑問と、コードを使って理解したことを残す。仕様や完了条件の正本ではない。

## 最初の論点

- 42 の Life における `board[y * width + x]` と、C++ の `std::vector`。
- 現在/次の盤面、同期更新、境界条件。
- 近傍 8 セルの集計から、畳み込みへの拡張。
- 固定時間刻み、連続値、数値の発散。
- メモリの所有、計算量、描画とモデルの切り分け。

## 書き方

- 疑問ごとに 1 ファイル、または 1 節。
- 実験結果や参考資料の出典を添える。
- 観察結果がフェーズの判断を変えたら、該当する [phases/](../phases/) の文書や [decisions/](../decisions/) に反映する。
