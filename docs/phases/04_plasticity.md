# Phase 4 — 可塑性

**読者:** 実装者(本人とコーディングエージェント)。
**状態:** 実装対象(2026-09-24、本人が [Phase 3 の報告](03_report.md) を確認し、以下を決定)。本人が観察して判断するまで Phase 5 以降に進まない。
**役割:** Phase 4 の実装範囲と完了条件の正本。共通ルールは [CLAUDE.md](../../CLAUDE.md)、測定方法は [02_experiment_protocol.md](../02_experiment_protocol.md)。

## Phase 3 を受けて確定したこと

- **書き換える数字は「音への敏感さ」(反応の強さ、コードでは `stim_gain`)だけ。** 丈夫さ(sigma)と体の濃さの基準(mu)は書き換えない。
- **個体全体で 1 つの数。** Phase 3 の m と同じ構造。格子の上の場にはしない。
- **変化は非常にゆっくり戻る(数分)。** 完全に固定はしない。うるさい環境で下がり、静かな時間で元の値に向かって戻る。元の値を超えて上がることはない。
- **作品向けの既定は、順応の時定数 10 秒、勾配の形は cos 型。** 窓アプリ(`cave_window`)の既定値にする。実験用 CLI(`cave`)の既定は Phase 2・3 の再現を壊さないよう変えない。

## 狙い

Phase 3 の慣れ(m)は静かにすれば数十秒で消えた。Phase 4 では、経験による変化が静かな時間の後にも残るか(何分残るか)を測る。[00_vision.md](../00_vision.md) の性質 4「可塑性」。

## 仕組み

個体は反応の強さ g を自分で持つ(初期値は設定した `stim_gain` = g0)。毎ステップ:

```text
g  -=  r · m · g                 うるさいほど(m が大きいほど)下がる
g  +=  (g0 − g) / τ_return        静かな時間に元の値へゆっくり戻る
g_eff = g / (1 + k·m)             Phase 3 の順応はそのまま重なる
```

- r: 下がる速さ(CLI では 1 秒あたりで指定し、ステップに換算)。r = 0 で無効、そのとき Phase 3 とバイト一致。
- τ_return: 戻る時定数(秒)。数分の桁。
- 一定の m のもとでの落ち着き先は `g = g0 / (1 + r·τ_return·m)`。

## 実装範囲

1. **可塑性の状態変数 g。** Lenia に `plast_rate`(ステップあたり)と `plast_return_steps` を追加。g はチェックポイントに含め、`metrics.csv` に `plast_g` として記録する。
2. **CLI と窓アプリ。** `--plast-rate`(1 秒あたり)と `--plast-return`(秒)。窓アプリの既定を cos 型・順応 k=3・tau 10 秒にし、タイトルに g を出す。
3. **実験。** 環境 3 条件(静か / 密なパルス / 連続)で 2 分過ごさせ、共通の無音(30 秒 / 2 分 / 5 分)の後に同じ探針を与える。可塑性あり(r>0)と、なし(r=0、順応のみ = Phase 3 の対照)を比べる。探針応答と、探針時の m と g を記録する。r を 3 段階で振る。
4. **コードの説明。** 2 つの時定数(順応と可塑性)の関係、落ち着き先の式、r=0 の迂回、チェックポイント。

## この段階で含めないもの

sigma・mu の書き換え、格子上の場としての可塑性、複数個体、マイク、周波数帯、LLM。

## 完了条件

- `plast_rate = 0` の run が Phase 3 とバイト一致する(テスト)。
- 同じ探針に対して、可塑性ありでは長い無音(2 分以上)の後にも環境による応答の差が残り、可塑性なしでは消えることが数値で示されている。
- 探針時の g が環境ごとに記録され、落ち着き先の式と整合している。
- 戻る時定数どおりに g が回復することが示されている。
- 数値異常や消滅があれば条件を隠さず記録する。
- Phase 5〜7(任意)に進むか、作品の仕上げに向かうかを判断する材料として、4 つの性質(自律運動・刺激応答・履歴・可塑性)がそれぞれどこまで示せたかをまとめる。
