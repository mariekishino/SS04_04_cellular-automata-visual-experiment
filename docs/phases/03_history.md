# Phase 3 — 履歴

**読者:** 実装者(本人とコーディングエージェント)。
**状態:** 実装済み(2026-09-24、コミット 23153f9)。報告は [03_report.md](03_report.md)。実曲での比較は本人の判断で省略。本人が観察して判断するまで Phase 4 に進まない。
**役割:** Phase 3 の実装範囲と完了条件の正本。共通ルールは [CLAUDE.md](../../CLAUDE.md)、測定方法は [02_experiment_protocol.md](../02_experiment_protocol.md)。

## Phase 2 を受けて確定したこと

- **履歴の機構は順応。** 刺激振幅の指数移動平均 m(t) をモデル内の遅い状態変数として 1 つ持ち、実効的な反応の強さ(コードでは `stim_gain`)を `g_eff = g / (1 + k·m)` に下げる。大きな音が続くと、同じ音への応答が小さくなる。m はチェックポイントに含める。
- **時定数は 3 つを比較する。** 2 s / 10 s / 60 s(実時間。60 steps/s なので 120 / 600 / 3600 ステップ)。
- **勾配の形に cos 型を追加する。** `h = (1 − cos(2πx/W)) / 2`。周期境界の継ぎ目で連続。線形勾配と比べ、Phase 2 で見た「向きが真下に寄る」が継ぎ目の影響かを分離する。
- **音源は合成パルスと本人の MP3。** 履歴の差は合成パルスで条件を揃えて測り、実曲でも同じ手順で数値を取る。
- **向きは履歴の指標から除外する。** 向きは中立安定なので、履歴の効果は探針への応答の大きさ(総量・速度・広がりの変化)で測る。
- 入り口は Phase 2 の growth を主に使う(mu は許容幅が狭い)。

## 狙い

現在の音が同じでも、それまでの刺激が違えば応答が違うか([00_vision.md](../00_vision.md) の性質 3)。刺激を止めた後、その差がどのくらいの時間残るか。

## 実装範囲

1. **遅い状態変数。** Lenia に `adapt_k`(強さ、0 で無効)と `adapt_tau_steps`(時定数、ステップ)を追加し、毎ステップ `m += α (s − m)`、`α = 1 − exp(−1/τ)`。`adapt_k = 0` または `m = 0` のとき Phase 2 とバイト一致することをテストする。m を `metrics.csv` に記録する。
2. **cos 型の形。** `StimulusShape::CosX` を追加する。
3. **探針。** 履歴用の入力(パルス列または WAV)に、指定時刻の短い探針パルスを重ねられるようにする(`--probe-at / --probe-dur / --probe-amp`)。WAV は `--wav-until` で指定秒以降を無音にできる。
4. **実験。** 履歴 3 条件(無音 / まばらなパルス / 密なパルス)× 時定数 3 × 順応あり/なし。共通の無音区間の後に同じ探針を与え、応答(探針中の総量増)を比べる。時定数ごとに、無音区間の長さを変えて差が消えるまでの時間を測る。cos と線形の勾配で向きの推移を比べる。実曲でも履歴あり/なしで探針応答を比べる。
5. **窓アプリ。** `--adapt-k / --adapt-tau` を渡せるようにし、タイトルに m を出す。
6. **コードの説明。** 遅い変数の更新順序、時定数とステップの換算、チェックポイントへの追加、探針の重ね方。

## この段階で含めないもの

可塑性(係数そのものの更新)、空間的な m(セルごとの順応)、複数個体、マイク、周波数帯。

## 完了条件

- `adapt_k = 0` の run が Phase 2 とバイト一致する(テスト)。
- 同じ探針に対して、履歴が違えば応答が違う(順応あり)ことと、順応なしなら同じであること(対照)が数値で示されている。
- 履歴の差が無音区間の後にどれだけ残るかが、時定数ごとに示されている。
- cos 型と線形勾配で、向きの推移の違い(または同じであること)が記録されている。
- 実曲で履歴あり/なしの探針応答が比べられている(MP3 が用意でき次第)。
- 数値異常や消滅があれば条件を隠さず記録する。
- Phase 4(可塑性)で更新する係数の候補を、観察に基づいて提案する。
