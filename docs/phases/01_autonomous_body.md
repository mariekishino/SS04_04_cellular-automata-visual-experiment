# Phase 1 — 無音でも動く身体(草案)

**読者:** 実装者(本人とコーディングエージェント)。
**状態:** 計画のみ。Phase 0 の結果と本人の観察を受けて内容を更新するまで、実装指示ではない。
**役割:** Phase 1 の骨子。確定したら「状態」を「実装対象」に変え、実装範囲・完了条件・エージェントへの指示文を追加する。

## 狙い

Phase 0 で選んだ 1 モデルを基に、自律運動を長く観察できる単体アプリを作ります。音も履歴もまだ付けません。

## 候補となる要件

- seed または初期状態の再現
- 固定時間刻み
- 現在/次の盤面の分離
- 停止・再開・リセット
- 指標の表示

局所的なまとまりが、消滅・全面飽和・静止せずに変化を続ける条件を探索します。

## Phase 0 の後に確定すること

- 採用モデルと更新式、表示に適した解像度と境界条件。
- 「まとまり」と「動いている」を判断する観測指標と、観察時間。
- 観測した安定条件、失敗条件、負荷。モデルが目的に合わなければ Phase 0 に戻る。

これらを決めずに、任意のプリセットや固定値を「完成した身体」として採用しません。Phase 1 の成果を本人が確認した後で、Phase 2 の音入力を詳細設計します。
