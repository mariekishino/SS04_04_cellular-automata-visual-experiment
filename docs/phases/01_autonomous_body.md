# Phase 1 — 無音でも動く身体

**読者:** 実装者(本人とコーディングエージェント)。
**状態:** 実装済み(2026-09-24、コミット 7255598)。報告は [01_report.md](01_report.md)。実機(Mac)での窓表示は本人が確認済み。本人が観察して判断するまで Phase 2 に進まない。
**役割:** Phase 1 の実装範囲と完了条件の正本。共通ルールは [CLAUDE.md](../../CLAUDE.md)、測定方法は [02_experiment_protocol.md](../02_experiment_protocol.md)。

## Phase 0 を受けて確定したこと

- **採用モデル:** Lenia 型、Orbium パラメータ(R=13, mu=0.15, sigma=0.015, dt=0.1)。
- **境界条件:** 周期境界のみ。固定境界は両モデルで人工物を生み、Lenia では個体が壁で消滅した(L2)。
- **Gray–Scott:** コードは残す(Model インターフェースの 2 実装目として)。Phase 1 の観察対象にはしない。
- **表示:** SDL3 の窓表示を CMake オプションとして追加する。VM では仮想ディスプレイで動作を検証し、実機の窓は本人が Mac か Windows でビルドして確認する。PNG 出力は記録用として残す。

## 狙い

Orbium を長く観察できる単体アプリを作り、「まとまりを保って動き続ける」を数値で言えるようにする。音も履歴もまだ付けない。

## 実装範囲

1. **まとまりと動きの指標。** チャンネル 0 について、周期境界に対応した重心、スナップショット間の速度、重心まわりの広がり(RMS 半径)、閾値以上のセルの連結成分数を記録する。`metrics.csv` に列を追加する。
2. **単体アプリ(窓表示)。** SDL3 で状態を描画する。更新は固定時間刻みで、描画フレーム数から切り離す(1 秒あたりのステップ数を指定)。キー操作: 停止/再開、1 ステップ、同 seed でリセット、スクリーンショット保存、速度の増減、終了。指標は定期的に端末に出す。CMake オプション `CAVE_WITH_SDL3`(既定 OFF)。
3. **長時間観察。** 64×64、96×96、128×128 の周期境界で 20000 ステップ以上(t≥2000)走らせ、持続・消滅・静止・全面飽和と指標の時系列を記録する。
4. **自発生成の頻度。** `blobs` 初期化を seed 1〜20 で 1000 ステップ走らせ、Orbium 型の個体が残った割合を記録する。「残った」の判定基準(総量・連結成分数の範囲)を明記する。
5. **コードの説明。** 重心の周期境界処理、連結成分の探索、固定時間刻みと描画の分離を、コードと対応させて説明する。

## この段階で含めないもの

音声入力、履歴、可塑性、複数個体の相互作用、パラメータの自動探索、FFT、GPU。

## 完了条件

- `CAVE_WITH_SDL3=ON` でビルドでき、仮想ディスプレイ上でアプリが起動して描画・停止・再開・リセットが動くことをスクリーンショットで示す。実機での確認は本人が行い、未確認なら未確認と書く。
- 3 つの格子サイズで 20000 ステップ以上の観察記録(指標の時系列、シート画像)がある。
- 自発生成の頻度が seed 20 通りで記録されている。
- 重心・速度・広がり・連結成分数のテストがある(周期境界の継ぎ目をまたぐ場合を含む)。
- 数値異常があれば条件を隠さず記録する。
- Phase 2 で音を入れる際の「刺激の入り口」候補(どのパラメータに作用させるか)を、観察に基づいて提案する。数値は固定しない。
