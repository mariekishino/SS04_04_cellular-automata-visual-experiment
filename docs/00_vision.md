# 00 — 作品の意図と問い

**読者:** 全員。この作品に関わる人、興味を持った人。
**役割:** 何を作りたいか、何を確かめたいかを言葉にする。実装の詳細は書かない。

## 作りたいもの

画面上で、まとまりを保ちながら自律的に動く、流体のような視覚的存在を作ります。

音楽はそれを起動するスイッチではなく、環境からの入力です。音が鳴っている間の反応だけでなく、音が止んだ後の動きや、次に音が来たときの応答に、過去の刺激の履歴が残るかを実験します。

## 中心の問い

> 局所的な更新だけで動く系に「刺激の履歴」と「可塑性」を加えると、同じ初期条件から出発しても、経験によって持続的な違いが生まれるか。

## 観察したい 4 つの性質

1. **自律運動:** 無音でも更新が続き、見える状態が変わり続ける。
2. **刺激応答:** 音から得た信号が内部状態の更新に影響し、形や密度の変化として見える。
3. **履歴:** 今鳴っている音が同じでも、それまでの刺激が違えば応答が違う。
4. **可塑性:** 音が止んだ後の平常時の動きや、次回の反応の仕方が変わる。

これらは実験で確かめる目標です。モデルを採用しただけで成立する性質ではありません。

## 言葉の扱い

- 色が変わっただけでは「適応」と呼びません。
- 「生命体」「記憶」「成長」は表現上の言葉です。生物学的な生命や学習を証明したとは扱いません。

## 設計の原則

- **結果を先に固定しすぎない。** 「低音なら赤くなる」「何があっても特定の性格を保つ」のような最終結果を、実装前に決めない。
- **一方で、枠は定義する。** 更新則、パラメータの可変範囲、境界条件、刺激の入り方は決める。「何も決めずに自己変容する」実装はできない。
- **予想外を歓迎できるように記録する。** seed、初期状態、入力、設定を残し、面白い現象と数値の破綻を区別できるようにする。
- **層を分ける。** 音の特徴量、内部状態、描画結果は別々に扱う。見た目が流体風でも、流体の物理計算とは限らない。

## 範囲

- Phase 0〜1: 音なしでモデルを選び、自律運動を作る。
- Phase 2: 音を与える。
- Phase 3〜4: 履歴と可塑性を調べる。
- それ以降: 更新則の構造変化、複数個体、LLM は必要に応じた後半のテーマ。
