# 02 — 実験・測定方法

**読者:** 実装者(本人とコーディングエージェント)。
**役割:** 各試行で何を記録し、何を測り、何を「失敗」と呼ぶかを決める。報告の様式は [.claude/skills/phase-report/SKILL.md](../.claude/skills/phase-report/SKILL.md) にある。

## 各試行に残す設定

次の項目をすべて残します。どれか一つ欠けると再現できません。

| 項目 | 内容 |
| --- | --- |
| `model` | モデル名(例: Lenia 型、Gray–Scott 型) |
| `code_version` | コミットハッシュなど |
| `grid_size` | 格子の幅と高さ |
| `initial_state_or_seed` | seed、または明示的な初期配置 |
| `boundary` | 周期境界か固定境界か |
| `timestep` | 固定時間刻み `dt` |
| `model_parameters` | モデル固有のパラメータ |
| `input_sequence` | 刺激の入力列(Phase 0〜1 では無音) |
| `duration` | 実行したステップ数または時間 |

## 各試行に残す観測

- 開始時と終了時の画像、または短い動画。
- 経時的な数値(下の指標)。

録画手段がなければ、設定とスクリーンショットでもかまいません。ただし、観測できていない挙動を記載しません。

## 最小の指標

| 指標 | 内容 |
| --- | --- |
| 最小・最大 | 状態値の範囲 |
| 総量 | 状態値の合計 |
| 変化量 | 前フレームからの差分 |
| 占有セル数 | 閾値以上のセル数。閾値の値も記録する |

まとまりの移動を見る段階になったら、重心や境界の指標を追加します。計測のためにモデルを変えません。

## Phase 0〜1 での比較手順

1. 各モデルの更新式、初期条件、境界処理を明記する。
2. 同じモデル・同じ設定を再実行し、出力が再現するかを確かめる。
3. 局所的な模様の持続、移動、周期、消滅、全面飽和を観察する。
4. 数値が有限かを確かめる。NaN/Inf があれば、演出と区別して失敗として記録する。

異なる数式のモデルに同じ数値パラメータを与えても、比較の意味はありません。モデル間の比較は「どの条件で、どんな動きが出たか」で行い、採用理由と不採用理由を残します。

## Phase 2 以降の刺激実験

- 同じ初期スナップショットから、無音／短い合成刺激／継続刺激の 3 つを比較する。
- Phase 3〜4 では、刺激を止めて共通の無音区間を置いた後、全試行に同じ短い音を与える。即時応答、減衰中の履歴、持続した変化を分けて評価する。

## 「差が出た」と言うための条件

- 複数個体で差が出ても、乱数消費順、時間刻み、初期状態が異なれば「刺激履歴による差」とは言えません。
- 差が出なかった実験も保存します。
- 変化が観察できたら、映像だけでなく内部変数でも確認します。
