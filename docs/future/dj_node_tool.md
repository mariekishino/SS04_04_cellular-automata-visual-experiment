# 将来メモ — DJ Node Tool との接続可能性

**読者:** 本人(制作者)。
**役割:** 今は範囲外の構想を、忘れないように置いておく。現在のフェーズの仕様には影響しない。

## 前提

この作品は DJ Node Tool とは別のリポジトリで進めます。DJ 側も開発途中です。**接続は現在の実装範囲にも完成条件にも含めません。**

## 将来の構想

両方が動くようになった後で、DJ 側の最終ミックスから得た時刻付きの特徴量(音量、周波数帯など)を、この作品の刺激入力に渡せるかもしれません。体験としては、音のミックス、ノードの操作画面、人工生命の映像が並ぶ形を想像しています。

## 今守ることは 1 つだけ

シミュレーションの中核を、音声デバイスと描画ライブラリから切り離しておくこと([decisions/0001](../decisions/0001_language_and_boundaries.md))。

通信方式、ブラウザ実行、WebAssembly、ノードの形式、リアルタイム同期方式は、両プロジェクトの実態を確認してから判断します。将来の構想を理由に、現在の Phase 0〜4 に DJ 固有の仕様を追加しません。
